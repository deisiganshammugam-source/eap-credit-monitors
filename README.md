# EAP credit monitors

Static hosting (GitHub Pages) for two interactive monitors built from public data:

- `credit_cyclicality_dashboard.html`: Credit Cyclicality Monitor (does bank credit move with the business cycle? 21 economies).
- `credit_gap_dashboard.html`: Credit-to-GDP Gap Monitor (BIS gaps for 44 economies plus staff estimates).

Both files are generated by the pipelines in the `malaysia-macro-analyst` repository (`credit_cyclicality/` and `credit_gap/`) and copied here after each refresh (`credit_cyclicality/publish_pages.sh`). Each file bundles its chart library, so it works offline once loaded; the web font loads from Google Fonts when online. Draft for internal discussion.
